# VideoRAG 기술 출처 정리 (Source Attribution)

이 문서는 VideoRAG 프로토타입의 각 모듈이 참조하는 논문, GitHub 저장소, 표준 규격을 정리한 것이다.

## 1. Phase 0 — 인덱싱

### 1-1. Shot 탐지 (TransNetV2) — `src/phase0_indexing/shot_detector.py`
- **논문:** Souček & Lokoč (2020), "TransNet V2: An effective deep network architecture for fast shot transition detection", ICML Workshop
- **GitHub:** https://github.com/soCzech/TransNetV2 (MIT License)
- **추가:** scikit-learn Agglomerative Clustering (Scene 그룹핑)

### 1-2. 영상 임베딩 (InternVideo2) — `src/phase0_indexing/embedder.py`
- **논문:** Wang et al. (2024), "InternVideo2: Scaling Foundation Models for Multimodal Video Understanding", CVPR 2024
- **GitHub:** https://github.com/OpenGVLab/InternVideo/tree/main/InternVideo2
- **모델:** OpenGVLab/InternVideo2-Stage2_1B-224p-f4 (HuggingFace)
- **폴백:** CLIP ViT-B/32 (OpenAI)
- **정부과제 연계:** 연구개발계획서 §기술 현황 — InternVideo2-6B (MSR-VTT R@10 = 85.1%)

### 1-3. 벡터 인덱스 (FAISS) — `src/phase0_indexing/vector_store.py`
- **논문:** Johnson, Douze & Jégou (2019), "Billion-scale similarity search with GPUs", IEEE Transactions on Big Data (원본: ICML 2017 Workshop)
- **GitHub:** https://github.com/facebookresearch/faiss (MIT License, Meta AI Research)
- **구현:** IVFFlat (nlist=100, nprobe=10), IndexFlatIP (평가 전용)
- **정부과제 연계:** 연구개발계획서에서 Milvus(IVF_PQ) 언급, 프로토타입은 FAISS 사용

### 1-4. 한국어 캡션 생성 [DEPRECATED] — `src/phase0_indexing/caption_ko.py`
- **API:** OpenAI GPT-4o-mini Vision API
- **비고:** 현재 미사용 (사전 생성된 캡션을 ClipMeta.ko_caption에 로드)

## 2. Phase 1-2 — 검색과 융합

### 2-1. BM25 검색 — `src/phase12_search/bm25_retriever.py`
- **이론:** Robertson & Zaragoza (2009), "The Probabilistic Relevance Framework: BM25 and Beyond", Foundations and Trends in IR
- **라이브러리:** dorianbrown/rank_bm25 (Apache 2.0) — https://github.com/dorianbrown/rank_bm25
- **토크나이저:** spaCy en_core_web_sm (영어 레마타이저)

### 2-2. Dense 검색 — `src/phase12_search/dense_retriever.py`
- **이론:** Karpukhin et al. (2020), "Dense Passage Retrieval for Open-Domain Question Answering", EMNLP 2020
- **구현:** FAISS 기반 코사인 유사도 검색 (InternVideo2 512-dim 벡터)

### 2-3. Hybrid Fusion (WRRF) — `src/phase12_search/hybrid_fusion.py`
- **논문:** Cormack, Clarke & Butt (2009), "Reciprocal Rank Fusion outperforms Condorcet and individual Rank Learning Methods", SIGIR 2009
- **구현:** Weighted RRF — WRRF(d) = w_visual × 1/(k+rank_dense) + w_text × 1/(k+rank_sparse)
- **파라미터:** w_visual=0.6, w_text=0.4, k=60 (MSR-VTT nDCG 최적화)

## 3. Phase 3 — 리랭킹

### 3-1. ColBERT v2 + PLAID — `src/phase3_reranking/reranker.py`
- **논문 (ColBERT):** Khattab & Zaharia (2020), "ColBERT: Efficient and Effective Passage Search via Contextualized Late Interaction over BERT", SIGIR 2020
- **논문 (ColBERT v2):** Santhanam et al. (2022), "ColBERTv2: Effective and Efficient Retrieval via Lightweight Late Interaction", SIGIR 2022 (NAACL 2022)
- **논문 (PLAID):** Santhanam et al. (2022), "PLAID: An Efficient Engine for Late Interaction Retrieval", CIKM 2022
- **라이브러리:** bclavie/RAGatouille (Apache 2.0) — https://github.com/bclavie/RAGatouille
- **수식:** MaxSim score(Q,D) = Σ_{q_i∈Q} max_{d_j∈D} (E_q_i · E_d_j)

## 4. Phase 4 — 영상 어셈블리

### 4-1. DINOv2 시각 유사도 — `src/phase4_assembly/visual_scorer.py`
- **논문:** Oquab et al. (2024), "DINOv2: Learning Robust Visual Features without Supervision", TMLR 2024 (Meta AI)
- **GitHub:** https://github.com/facebookresearch/dinov2 (Apache 2.0)
- **모델:** dinov2_vitb14 (PyTorch Hub), 폴백: timm vit_base_patch14_dinov2
- **용도:** 전환 유형 결정, 클립 순서 정렬, TC-Score 계산

### 4-2. 전환 선택 — `src/phase4_assembly/transition_selector.py`
- **기반:** DINOv2 코사인 유사도 임계값 (자체 설계)
  - sim ≥ 0.6 → CUT (직접 연결)
  - 0.3 ≤ sim < 0.6 → CROSSFADE (0.5초 디졸브)
  - sim < 0.3 → MORPH (0.48초 광학 흐름 보간)

### 4-3. Morph 전환 — `src/phase4_assembly/morph_transition.py`
- **이론:** Farnebäck (2003), "Two-Frame Motion Estimation Based on Polynomial Expansion", Springer LNCS
- **구현:** OpenCV Farneback Dense Optical Flow 기반 프레임 보간

### 4-4. 색보정 (DreamColour 3D LUT) — `src/phase4_assembly/colour_normalizer.py`
- **논문/프로젝트:** DreamColour — Training-free color grading
- **GitHub:** https://github.com/CHAITron/DreamColour
- **구현:** LAB 공간 통계 색상 전이 → 3D LUT (17³ grid) → .cube 포맷 내보내기

### 4-5. TC-Score (시간 일관성) — `src/phase4_assembly/tc_scorer.py`
- **기반:** Farneback Optical Flow magnitude normalization (자체 설계)
- **정부과제 연계:** 연구개발계획서 TC-Bench (Temporal Consistency Benchmark)

### 4-6. 스토리보드 매퍼 — `src/phase4_assembly/storyboard_mapper.py`
- **기반:** Scene Graph JSON → 아카이브 클립 매핑 (자체 설계)
- **3경로 분기:** USE_AS_IS / TRANSFORM (Runway Gen-3) / GENERATE (Runway Gen-3)

### 4-7. Inverse Prompt Engine — `src/phase4_assembly/inverse_prompt_engine.py`
- **기반:** 속성 차이 → Runway 프롬프트 변환 (자체 설계)
- **API:** OpenAI GPT-4o-mini (동적 프롬프트 생성)

### 4-8. 비디오 어셈블러 — `src/phase4_assembly/assembler.py`
- **라이브러리:** MoviePy (비디오 편집), FFmpeg (인코딩)

## 5. Phase 5 — 콘텐츠 출처 추적

### 5-1. C2PA 서명 — `src/phase5_c2pa/c2pa_tagger.py`
- **표준:** C2PA (Coalition for Content Provenance and Authenticity) — https://c2pa.org/specifications/
- **서명:** ES256 (ECDSA P-256 + SHA-256, RFC 7518)
- **라이브러리:** Python cryptography (PyCA)
- **정부과제 연계:** 연구개발계획서 C2PA Working Group 참여 계획, C2PA 확장 표준안

## 6. 환각 탐지

### 6-1. PRISM + WCS — `src/hallucination/hallucination_detector.py`
- **논문 (PRISM):** Azaria et al. (2023), "The Internal State of an LLM Knows When It's Lying", EMNLP 2023
- **WCS (World Consistency Score):** 4-track 물리 일관성 검증 (자체 설계)
  - Object Persistence (ORB), Relative Scale (Canny), Color Consistency (HSV), Frame Physics (Optical Flow)
- **정부과제 연계:** 연구개발계획서 환각 탐지 정확도 ~75% 목표

## 7. 입력 전처리

### 7-1. 쿼리 전처리 — `src/input/query_preprocessor.py`
- **API:** Naver Papago (한국어→영어 번역)
- **라이브러리:** langdetect (언어 감지)

### 7-2. 대본 파서 — `src/input/script_parser.py`
- **API:** OpenAI GPT-4o-mini (JSON mode, temp=0.3)
- **구현:** 대본 → Scene Graph JSON 자동 파싱 (자체 설계)

## 8. 평가

### 8-1. Exact-Search 인덱스 — `src/evaluation/faiss_flat_eval.py`
- **기반:** FAISS IndexFlatIP (brute-force exact search)
- **벤치마크:** MSR-VTT 1k-A split, InternVideo2 paper Table 24a 대조

### 8-2. 평가 메트릭 — `src/evaluation/metrics.py`
- **이론:** Manning, Raghavan & Schütze (2008), "Introduction to Information Retrieval", Cambridge University Press
- **메트릭:** Recall@K, nDCG@K, TC-Score, Hallucination Rate

## 9. 핵심 데이터 모델 — `src/data_models.py`
- **표준:** C2PA manifest 구조 (https://c2pa.org/specifications/)
- **설계:** 자체 설계 (ClipMeta, ClipResult, CurationState, VideoRAGResult 등)

## 10. 파이프라인 오케스트레이터 — `src/pipeline.py`
- **설계:** 자체 설계 (Phase 0-5 전단계 조율)

## 정부과제 연구개발계획서 참조 기술 vs 프로토타입 구현 대조

| 계획서 기술 | 프로토타입 구현 | 비고 |
|---|---|---|
| InternVideo2-6B | InternVideo2-1B | T4 GPU 제약으로 1B 사용 |
| Milvus (IVF_PQ) | FAISS (IVFFlat) | 단일 노드 프로토타입에 적합 |
| ColBERT v2 | ColBERT v2 (RAGatouille) | 동일 |
| C2PA 표준 | C2PA ES256 서명 | 동일 |
| PRISM 환각 탐지 | PRISM + WCS 이중 트랙 | WCS 추가 구현 |
| TC-Bench | TC-Score (Optical Flow) | 자체 메트릭 |
| VBench 2024 | 미구현 | 향후 과제 |
| Runway Gen-3 | API 연동 (storyboard_mapper) | TRANSFORM/GENERATE 경로 |
