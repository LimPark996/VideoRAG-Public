## 전체 흐름 — 인덱싱 → 검색 (End to End)

---

### 🗂️ 인덱싱 (오프라인, 1회)

**진입점: `VideoIndexer.build_index(video_dir, metadata_csv)`**

---

**① `_load_metadata_csv()` 또는 `_build_clips_from_videos()`**
| | |
|---|---|
| 입력 | `video_dir: str`, `metadata_csv: str` (선택) |
| 출력 | `List[ClipMeta]` — clip_id, caption, video_path, start/end_ms, scene_id |
| 기능 | CSV 있으면 행마다 ClipMeta 생성. 없으면 ShotDetector로 장면 탐지 후 생성. end_ms는 항상 cv2로 직접 측정 (CSV 값 부정확) |

---

**② `_extract_clip_frames(clips)`**
| | |
|---|---|
| 입력 | `List[ClipMeta]` |
| 출력 | `List[List[ndarray]]` — `[N, 4, H, W, 3]` uint8 RGB |
| 기능 | 클립당 4프레임 균등 샘플링 (`start + duration/4 × (i+0.5)`). 실패 프레임은 랜덤 더미 대체. 2번째 프레임을 썸네일 jpg로 저장 |

---

**③ `VideoEmbedder.encode_clips(frames)` → ITC 임베딩**
| | |
|---|---|
| 입력 | `List[List[ndarray]]` — `[N, 4, H, W, 3]` |
| 출력 | `ndarray [N, 512] float32` |
| 기능 | `frames2tensor()` → `model.get_vid_feat()` — vision encoder → `vision_proj(pooled CLS)` → 512-dim → L2 정규화 |

---

**④ `FAISSVectorStore.build_index(embeddings, clip_ids)`**
| | |
|---|---|
| 입력 | `ndarray [N, 512]`, `List[clip_id]` |
| 출력 | `faiss_ivfflat.index` + `.ids.pkl` 저장 |
| 기능 | IVFFlat 훈련 (nlist=100) → 벡터 add → FAISS 내부 ID ↔ clip_id 매핑 구성 |

---

**⑤ `_build_bm25_index(captions, clip_ids)`**
| | |
|---|---|
| 입력 | `List[caption]`, `List[clip_id]` |
| 출력 | `bm25_index.pkl` 저장 |
| 기능 | `SpacyLemmatizerTokenizer.tokenize()` → 전체 caption lemmatize + 불용어 제거 → `BM25Okapi` 역인덱스 구축 (k1=1.5, b=0.75) |

---

**⑥ `pickle.dump(clip_metadata)`**
| | |
|---|---|
| 입력 | `{clip_id → ClipMeta}` |
| 출력 | `clip_metadata.pkl` 저장 |
| 기능 | 쿼리 타임에 clip_id → video_path, caption, 구간 역조회용 |

---

**⑦ `VideoEmbedder.encode_clips_itm(frames)` → ITM feature 사전 추출 (선택)**
| | |
|---|---|
| 입력 | `List[List[ndarray]]` — ②와 동일한 프레임 |
| 출력 | `itm_vision_features.pt` 저장 — `{clip_ids, Tensor[N, 1025, 1408] fp16}` |
| 기능 | `model.encode_vision(batch, test=True)[0]` — vision encoder **전체 토큰** last_hidden_state 반환 (③의 pooled CLS와 다름). ColBERT 이후 ITM 재순위 시 영상 재인코딩 없이 바로 로드하기 위해 사전 저장 |

---

### 🔍 검색 (쿼리 타임, 매번)

**진입점: `pipeline.search_only(query)` → `_run_search_pipeline(query)`**

---

**⑧ `QueryPreprocessor.preprocess(query)`**
| | |
|---|---|
| 입력 | `query: str` — 한/영 자연어 |
| 출력 | `en_query: str` |
| 기능 | 한국어 감지 시 Papago 번역. 이후 모든 단계는 en_query만 사용 |

---

**⑨ `BM25Retriever.search(en_query, top_n=100)`**
| | |
|---|---|
| 입력 | `en_query: str` |
| 출력 | `List[(clip_id, bm25_score)]` ×100 |
| 기능 | `SpacyLemmatizerTokenizer.tokenize(en_query)` → `BM25Okapi.get_scores()` → 상위 100개 |

---

**⑩ `VideoEmbedder.encode_query(en_query)` → ITC 텍스트 임베딩**
| | |
|---|---|
| 입력 | `en_query: str` |
| 출력 | `ndarray [1, 512] float32` |
| 기능 | `BertTokenizer` → `model.get_txt_feat()` — BERT-large → `text_proj(CLS 1개)` → 512-dim → L2 정규화 |

---

**⑪ `FAISSVectorStore.search(query_vec, k=100)`**
| | |
|---|---|
| 입력 | `ndarray [1, 512]` |
| 출력 | `List[(clip_id, cosine_sim)]` ×100 |
| 기능 | IVFFlat inner product 검색 (nprobe=10) → FAISS 내부 ID → clip_id 역매핑 |

---

**⑫ `HybridFusion.fuse(sparse, dense)`**
| | |
|---|---|
| 입력 | BM25 결과 ×100, FAISS 결과 ×100 |
| 출력 | `List[(clip_id, wrrf_score)]` ×100~200 |
| 기능 | `score = 0.4×1/(60+rank_bm25) + 0.6×1/(60+rank_dense)` — 두 리스트 합집합 대상 |

---

**⑬ `ColBERTReranker.rerank(en_query, fused[:100], clip_captions, top_k=N)`**
| | |
|---|---|
| 입력 | `en_query: str`, `fused[:100]`, `{clip_id: caption}`, `top_k` |
| 출력 | `List[ClipResult]` ×N (ITM 활성이면 N = top_k×2.5) |
| 기능 | 쿼리 토큰 `[L_q, 768]` × caption 토큰 `[L_d, 768]` MaxSim: `Σ_q max_d (E_q·E_d)`. **caption 텍스트만 봄 — 영상 자체는 보지 않음**. PLAID centroid pruning으로 10~50x 가속 |

---

**⑭ `ITMScorer.rerank(en_query, colbert_results, top_k=20)` *(feature 있을 때만)***
| | |
|---|---|
| 입력 | `en_query: str`, `List[ClipResult]` ×N |
| 출력 | `List[ClipResult]` ×20 — score = ITM logit |
| 기능 | ① `encode_text(tok)[0]` → `[1, 40, 1024]` **전체 40토큰** (⑩의 CLS 1개와 다름)<br>② `vis_feat_dict[clip_id]` → 사전 저장된 `[1025, 1408]` 로드 (⑦에서 저장한 것)<br>③ `enc(text_40tok, vis_1025tok, mode="fusion")` — cross-attention<br>④ `itm_head(fusion_cls)[:,1]` — Linear(1024→2) 매칭 logit → 정렬 |

---

### 전체 한눈에

```
── 인덱싱 (오프라인) ──────────────────────────────────────────
video_dir
  │
  ① ClipMeta 생성  →  List[ClipMeta]
  │
  ② 프레임 추출   →  [N, 4, H, W, 3]
  │
  ├─ ③ encode_clips()      →  [N, 512]   →  ④ FAISS 저장
  ├─ ⑤ BM25 구축                         →     bm25.pkl 저장
  ├─ ⑥ clip_metadata 저장               →     metadata.pkl 저장
  └─ ⑦ encode_clips_itm()  →  [N, 1025, 1408]  →  itm_feat.pt 저장

── 검색 (쿼리 타임) ────────────────────────────────────────────
query
  │
  ⑧  번역          →  en_query
  ├─ ⑨  BM25       →  (clip_id, score) ×100
  ├─ ⑩  ITC 임베딩 →  [1, 512]
  └─ ⑪  FAISS      →  (clip_id, score) ×100
  │
  ⑫  WRRF Fusion   →  (clip_id, score) ×100~200
  │
  ⑬  ColBERT       →  ClipResult ×50   (caption↔query MaxSim)
  │
  ⑭  ITM           →  ClipResult ×20   (vision 1025tok ↔ text 40tok)
```
