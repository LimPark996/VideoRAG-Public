# VideoRAG 프로토타입 — 코드 전체 해설 (End-to-End)

이 문서는 VideoRAG 프로토타입의 `src/` 디렉토리에 있는 모든 파이썬 모듈과 `notebooks/` 디렉토리에 있는 모든 주피터 노트북을 처음부터 끝까지 읽고, 그 흐름을 한국어 줄글로 풀어 설명한 것이다. 코드를 직접 읽기 어려운 분들이 "이 프로젝트가 전체적으로 어떻게 돌아가는지"를 이해할 수 있도록, 마치 동료 개발자가 코드를 전부 뜯어본 뒤 구두로 설명해주는 것처럼 서술한다.

---

## 전체 구조 개관

이 프로젝트는 "방송사 PD가 텍스트 쿼리나 대본을 입력하면, 보유한 영상 아카이브에서 가장 적합한 클립을 찾아 자동으로 편집 영상을 만들어주는 시스템"이다. RAG(Retrieval-Augmented Generation)라는 개념을 텍스트가 아닌 영상에 적용한 것이라고 보면 된다. 전체 파이프라인은 Phase 0부터 Phase 5까지 여섯 단계로 나뉘며, 각 단계가 독립적인 모듈로 구현되어 있다.

Phase 0은 인덱싱이다. 영상 아카이브를 미리 분석해서 검색 가능한 형태로 만들어두는 사전 작업이다. Phase 1-2는 검색과 융합으로, 사용자 쿼리를 받아 BM25(텍스트 기반)와 FAISS(벡터 기반) 두 갈래로 후보 클립을 찾은 뒤 하나의 순위로 합친다. Phase 3은 리랭킹으로, ColBERT v2 모델을 사용하여 정밀 재순위를 매긴다. Phase 4는 어셈블리인데, 선택된 클립들을 실제 영상으로 조립하는 단계다. 여기에는 색보정, 트랜지션 선택, 시간 일관성 평가 등이 포함된다. Phase 5는 C2PA 디지털 서명으로, 완성된 영상의 출처를 증명하는 메타데이터를 붙인다.

이 외에 입력 전처리(한국어 쿼리 번역, 대본 파싱), 출력(NLE 타임라인 내보내기, 출처 리포트), 환각 탐지, 평가 모듈이 있다. 이 모든 것을 하나로 엮는 오케스트레이터가 `pipeline.py`이고, 노트북들은 이 파이프라인을 실제 Google Colab 환경에서 실행하는 가이드 역할을 한다.

**번역 체계:** 시스템의 모든 검색/인덱싱은 영어 기반이다. 한국어 입력은 경로별로 다른 수단으로 영어 번역된다. 쿼리는 Naver Papago API(`query_preprocessor.py`), 대본은 GPT-4o-mini가 Scene Graph JSON 생성 시 자동 번역(`script_parser.py`), 비디오 캡션은 사전 생성된 한국어 캡션을 `ClipMeta.ko_caption`에 보관한다(UI 표시용). 검색에는 항상 영어만 사용된다.

**TransitionType (18~28행)** — 트랜지션 유형 열거형이다.

```python
class TransitionType(Enum):
    CUT = "cut"            # 직접 붙이기 (유사도 0.6 이상)
    CROSSFADE = "crossfade" # 디졸브 효과 (유사도 0.3~0.6)
    MORPH = "morph"        # 광학 흐름 변형 (유사도 0.3 미만)
```

DINOv2로 계산한 두 클립 사이의 시각적 유사도에 따라 자동 선택된다. 유사도가 높으면 비슷한 장면이니 그냥 이어붙이고(CUT), 중간이면 부드럽게 전환하고(CROSSFADE), 낮으면 변형 효과로 연결한다(MORPH).

**ClipMeta (35~52행)** — 하나의 영상 클립 메타데이터를 담는 데이터클래스다.

```python
    end_ms: float                   # 40행: 클립 종료 시간(ms). scene 전체의 끝점
    video_path: str                 # 41행: 원본 영상 파일의 절대 경로
    keyframe_path: Optional[str] = None  # 42행: 대표 프레임 이미지 경로 (없을 수 있음)
    duration_ms: Optional[float] = None  # 43행: 클립 길이(ms). __post_init__에서 자동 계산
    scene_id: Optional[int] = None       # 44행: Agglomerative Clustering이 부여한 Scene 번호
```

**TransitionDecision (73~114행)** — 두 클립 사이의 트랜지션 결정 결과다.

```python
@dataclass
class TransitionDecision:
    transition_type: TransitionType     # 76행: CUT/CROSSFADE/MORPH 중 하나
    similarity_score: float             # 77행: DINOv2 코사인 유사도 (0~1)
    duration_sec: float                 # 78행: 트랜지션 지속 시간 (초)
    from_clip_id: str                   # 79행: 전환 출발 클립
    to_clip_id: str                     # 80행: 전환 도착 클립

    @staticmethod
    def from_similarity(sim: float, from_id: str, to_id: str) -> 'TransitionDecision':
        if sim >= 0.6:                  # 91행: 유사도 0.6 이상 → CUT (0초, 직접 이어붙임)
            return TransitionDecision(
                transition_type=TransitionType.CUT,
                similarity_score=sim, duration_sec=0.0,
                from_clip_id=from_id, to_clip_id=to_id)
        elif sim >= 0.3:                # 99행: 0.3~0.6 → CROSSFADE (0.5초 디졸브)
            return TransitionDecision(
                transition_type=TransitionType.CROSSFADE,
                similarity_score=sim, duration_sec=0.5,
                from_clip_id=from_id, to_clip_id=to_id)
        else:                           # 107행: 0.3 미만 → MORPH (1.0초 변형 효과)
            return TransitionDecision(
                transition_type=TransitionType.MORPH,
                similarity_score=sim, duration_sec=1.0,
                from_clip_id=from_id, to_clip_id=to_id)
```

핵심은 `from_similarity()` 클래스 메서드다. DINOv2 유사도 하나로 세 가지 트랜지션을 자동 선택한다.

**C2PAManifest (117~158행)** — C2PA 표준의 출처 추적 메타데이터다.

```python
@dataclass
class C2PAManifest:
    query: str                          # 125행: "밤에 도시 야경" 같은 원본 쿼리
    timestamp: str                      # 126행: ISO 8601 형식 생성 시간
    source_clips: List[Dict[str, Any]]  # 127행: 사용된 클립 목록 [{clip_id, video_path, ...}]
    signature: Optional[str] = None     # 128행: ES256 ECDSA 서명 (hex 문자열)
    manifest_version: str = "1.0"       # 129행: 매니페스트 버전
    generator: str = "VideoRAG-Prototype-v0.1"  # 130행: 생성기 식별자

    def to_dict(self) -> Dict[str, Any]:  # 132행: C2PA 표준 형식 딕셔너리 변환
        return {
            "c2pa:manifest": {
                "dc:title": f"VideoRAG Result: {self.query}",
                "c2pa:actions": [
                    {"action": "c2pa.searched", "parameters": {"query": self.query}},
                    {"action": "c2pa.assembled", "parameters": {
                        "clip_count": len(self.source_clips),
                        "clips": self.source_clips
                    }}
                ]
            }
        }
```

`to_dict()`는 C2PA 표준의 JSON-LD 형식으로 변환한다. `c2pa.searched`와 `c2pa.assembled` 두 액션이 기록되어 "이 영상은 검색 쿼리 X로 찾아서 Y개 클립을 조합해 만들었다"는 증거가 된다.

**CurationState (161~179행)** — PD 큐레이션 워크플로 상태 객체다.

```python
class CurationState:
```

**LatencyTracker (230~251행)** — 각 단계의 처리 시간을 측정하는 유틸리티다.

```python
@dataclass
class LatencyTracker:
    _start_times: Dict[str, float] = field(default_factory=dict)  # 233행: 단계별 시작 시간
    _latencies: Dict[str, float] = field(default_factory=dict)    # 234행: 단계별 소요 시간(ms)

    def start(self, phase: str):                   # 236행: 단계 시작 — time.perf_counter()로 시작점 기록
        self._start_times[phase] = time.perf_counter()

    def stop(self, phase: str) -> float:           # 239행: 단계 종료 — 경과 시간 계산(ms 단위)
        elapsed = (time.perf_counter() - self._start_times[phase]) * 1000
        self._latencies[phase] = elapsed
        return elapsed

    @property
    def total_ms(self) -> float:                   # 244행: 전체 소요 시간 합산
        return sum(self._latencies.values())
```

`time.perf_counter()`는 파이썬에서 가장 정밀한 시간 측정 함수다. `* 1000`으로 초를 밀리초로 변환한다.

### 2-1. Shot 탐지와 Scene 그룹핑 — `src/phase0_indexing/shot_detector.py`

영상을 인덱싱하려면 먼저 하나의 긴 영상을 의미 있는 단위로 잘라야 한다. `ShotDetector`가 이 역할을 한다.

#### 코드 상세 해설

**ShotInfo / SceneInfo 데이터클래스 (36~61행)**

```python
@dataclass
class ShotInfo:
    shot_id: int             # 38행: Shot 번호 (0부터 시작)
    start_ms: float          # 39행: Shot 시작 시간 (ms)
    end_ms: float            # 40행: Shot 종료 시간 (ms)
    scene_id: int = -1       # 41행: 소속 Scene ID (-1은 미할당)

@dataclass
class SceneInfo:
    scene_id: int            # 47행: Scene 번호
    shots: List[ShotInfo]    # 48행: 이 Scene에 속한 Shot들

    @property
    def start_ms(self) -> float:   # 50행: Scene의 시작 = 소속 Shot 중 가장 빠른 시작점
        return min(s.start_ms for s in self.shots)

    @property
    def end_ms(self) -> float:     # 54행: Scene의 끝 = 소속 Shot 중 가장 늦은 종료점
        return max(s.end_ms for s in self.shots)
```

SceneInfo의 `start_ms`/`end_ms`는 property로 구현되어 있어서, 내부 shots의 min/max를 자동 계산한다. 이것이 scene 전체 구간이 clip의 시간 범위가 되는 원리다.

**TransNetV2 Shot 탐지 (125~185행)** — 핵심 탐지 로직이다.

```python
def _detect_with_transnet(self, video_path, threshold):
    # 133행: TransNetV2가 영상을 48x27 픽셀로 리사이즈한 프레임을 읽어서
    # 각 프레임이 "Shot 경계일 확률"을 계산
    #
    # 예시: 30초 영상(25fps → 750프레임)
    # single_frame_preds → shape (750,) ← 프레임별 경계 확률
    #   [0.02, 0.01, 0.03, ..., 0.97, 0.02, ...]
    #                                 ↑ 이 지점이 97% 확률로 Shot 경계
    video_frames, single_frame_preds, all_frame_preds = \
        self.model.predict_video(video_path)   # 148행: TransNetV2 추론 실행

    fps = self._get_fps(video_path)            # 152행: FPS 확인 (보통 25.0)

    # 164행: 확률 > threshold(0.5)인 지점을 경계로 연속 프레임 구간 분할
    # 결과 예시: segments = [(0, 187), (188, 412), (413, 749)]
    segments = self.model.predictions_to_scenes(single_frame_preds, threshold=threshold)

    shots = []
    for start_frame, end_frame in segments:
        # 174행: 프레임 번호 → 밀리초 변환
        # 예: start_frame=188, fps=25.0 → start_ms = (188/25.0)*1000 = 7520ms
        start_ms = (start_frame / fps) * 1000
        end_ms = (end_frame / fps) * 1000
        shots.append((start_ms, end_ms))
    return shots
```

```python
def detect_scenes(self, video_path, threshold=0.5):
```

**색상 히스토그램 추출 (347~397행)**

```python
def _extract_shot_features(self, video_path, shots):
    for shot in shots:
        mid_ms = (shot.start_ms + shot.end_ms) / 2        # 376행: Shot 중간 지점
        cap.set(cv2.CAP_PROP_POS_MSEC, mid_ms)            # 377행: 해당 시점으로 이동
        ret, frame = cap.read()                            # 378행: 프레임 읽기

        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)       # 382행: BGR→HSV 색공간 변환
        hist = cv2.calcHist(
            [hsv], [0, 1], None,     # 383행: H(색조)와 S(채도) 2채널
            [32, 32],                # 385행: 각 채널 32bin → 32x32 = 1024차원 벡터
            [0, 180, 0, 256])        # 386행: H는 0~180, S는 0~256 범위
        hist = cv2.normalize(hist, hist).flatten()         # 389행: 정규화 후 1D로 펼침 [1024]
```

실내 인터뷰 Shot은 피부톤+사무실 색감이라 특정 H-S 분포를 갖고, 야외 전경은 하늘색+녹색이라 다른 분포를 갖는다. 이 히스토그램을 비교하면 비슷한 장소의 Shot들이 가까운 거리를 보인다.

**거리 행렬 구성 (399~455행)**

```python
def _compute_distance_matrix(self, shots, visual_features, visual_weight=0.7, temporal_weight=0.3):
    # 시각적 거리: Bhattacharyya 거리 (0=동일, 1=완전 다름)
    for i in range(n):
        for j in range(i + 1, n):
            d = cv2.compareHist(visual_features[i], visual_features[j],
                                cv2.HISTCMP_BHATTACHARYYA)  # 432행: 히스토그램 비교
            visual_dist[i, j] = d

    # 시간적 거리: Shot 중심점 간 시간 차이 (영상 길이로 정규화)
    centers = [(s.start_ms + s.end_ms) / 2 for s in shots]  # 446행: 각 Shot 중심점
    for i in range(n):
        for j in range(i + 1, n):
            d = abs(centers[i] - centers[j]) / total_duration  # 449행: 0~1 정규화

    # 가중 합산
    dist = 0.7 * visual_dist + 0.3 * temporal_dist  # 454행: 시각 70% + 시간 30%
```

시각적 유사도만 쓰면 영상 처음과 끝의 비슷한 장면이 하나로 묶이고, 시간적 근접성만 쓰면 연속이지만 다른 장면이 묶인다. 0.7/0.3 가중치로 균형을 잡는다.

### 2-4. FAISS 벡터 저장소 — `src/phase0_indexing/vector_store.py`

#### 코드 상세 해설

```python
class FAISSVectorStore:
    def __init__(self, dim=512, nlist=100, nprobe=10):
        self.dim = dim           # 벡터 차원 (512)
        self.nlist = nlist       # IVF 클러스터 수 (기본 100)
        self.nprobe = nprobe     # 검색 시 탐색할 클러스터 수 (기본 10)
        self.index = None        # FAISS 인덱스 객체
        self.id_map = []         # 벡터 인덱스 → clip_id 매핑

    def build(self, vectors, clip_ids):
        """인덱스 빌드 — IVFFlat 알고리즘"""
        import faiss
        # 1. 양자화기(quantizer) 생성: 코사인 유사도를 위해 Inner Product 사용
        quantizer = faiss.IndexFlatIP(self.dim)
        # 2. IVF 인덱스 생성: nlist개 클러스터로 벡터를 분류
        self.index = faiss.IndexIVFFlat(quantizer, self.dim, self.nlist, faiss.METRIC_INNER_PRODUCT)
        # 3. L2 정규화: 벡터를 단위벡터로 만들면 내적 = 코사인 유사도
        faiss.normalize_L2(vectors)
        # 4. 학습: 클러스터 중심점 계산
        self.index.train(vectors)
        # 5. 벡터 추가
        self.index.add(vectors)
        self.index.nprobe = self.nprobe  # 검색 시 10개 클러스터만 탐색
        self.id_map = list(clip_ids)

    def search(self, query_vec, top_k=100):
        """쿼리 벡터와 가장 가까운 K개 반환"""
        faiss.normalize_L2(query_vec)        # 쿼리도 L2 정규화
        scores, indices = self.index.search(query_vec, top_k)  # FAISS 검색
        results = []
        for score, idx in zip(scores[0], indices[0]):
            if idx >= 0:  # -1은 결과 없음
                results.append((self.id_map[idx], float(score)))
        return results
```

IVFFlat는 벡터들을 100개 클러스터로 나눈 뒤, 검색 시 쿼리와 가까운 10개 클러스터만 탐색하여 속도를 높인다. L2 정규화 후 내적을 계산하면 코사인 유사도와 동일한 결과를 얻는다.

```python
class SpacyLemmatizerTokenizer:
    """spaCy 기반 영어 토크나이저 — lemmatization으로 단어 정규화"""
    def __init__(self):
        import spacy
        self.nlp = spacy.load("en_core_web_sm")  # 소형 영어 모델 로드

    def tokenize(self, text):
        doc = self.nlp(text.lower())              # 소문자화 후 spaCy 처리
        tokens = []
        for token in doc:
            if token.is_stop or token.is_punct:   # 불용어, 구두점 제거
                continue
            tokens.append(token.lemma_)           # 표제어 추출: "playing"→"play"
        return tokens

class BM25Retriever:
    def __init__(self, tokenizer_mode='spacy'):
        self.tokenizer = SpacyLemmatizerTokenizer()  # 영어 spaCy 토크나이저
        self.bm25 = None              # rank_bm25 라이브러리의 BM25Okapi 인덱스
        self.clip_ids = []            # 문서 순서 → clip_id 매핑

    def build(self, clips):
        """BM25 인덱스 빌드"""
        tokenized_corpus = [self.tokenizer.tokenize(clip.caption) for clip in clips]
        # BM25Okapi: k1=1.5 (term frequency 포화 파라미터)
        #            b=0.75 (문서 길이 정규화 파라미터)
        self.bm25 = BM25Okapi(tokenized_corpus)
        self.clip_ids = [clip.clip_id for clip in clips]

    def search(self, query, top_n=100):
        """BM25 검색 — IDF × term frequency 점수로 상위 N개 반환"""
        query_tokens = self.tokenizer.tokenize(query)   # 쿼리도 같은 방식으로 토큰화
        scores = self.bm25.get_scores(query_tokens)     # 전체 문서에 대한 BM25 점수 배열
        top_indices = scores.argsort()[::-1][:top_n]    # 점수 내림차순 상위 N개 인덱스
        return [(self.clip_ids[i], float(scores[i])) for i in top_indices if scores[i] > 0]
```

Lemmatization 예시: "playing"/"played"/"plays" 모두 "play"로 변환되어, 같은 개념의 다양한 형태를 하나로 인식한다.

```python
    def __init__(self, w_visual=0.6, w_text=0.4, k=60):
        self.w_visual = w_visual  # Dense(시각) 가중치 (기본 0.6)
        self.w_text = w_text      # BM25(텍스트) 가중치 (기본 0.4)
        self.k = k                # RRF 상수 (기본 60)

    def fuse(self, bm25_results, dense_results):
        """WRRF(Weighted Reciprocal Rank Fusion) 실행"""
        # 각 결과에서 clip_id → 순위 매핑
        bm25_ranks = {cid: rank for rank, (cid, _) in enumerate(bm25_results, 1)}
        dense_ranks = {cid: rank for rank, (cid, _) in enumerate(dense_results, 1)}

        all_ids = set(bm25_ranks.keys()) | set(dense_ranks.keys())
        scores = {}
        for cid in all_ids:
            # WRRF 공식: score = w_text/(k + rank_bm25) + w_visual/(k + rank_dense)
            bm25_rank = bm25_ranks.get(cid, len(bm25_results) + 1)  # 없으면 최하위
            dense_rank = dense_ranks.get(cid, len(dense_results) + 1)
            scores[cid] = (self.w_text / (self.k + bm25_rank) +
                           self.w_visual / (self.k + dense_rank))

        # 점수 내림차순 정렬하여 반환
        fused = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return fused
```

k=60은 순위 차이를 완화하는 상수다. 1위와 2위의 점수 차이가 크지 않게 만들어서, 두 경로 모두에 나타나는 클립이 자연스럽게 상위에 올라간다.

### 5-1. ColBERT v2 리랭커 — `src/phase3_reranking/reranker.py`

```python
class ColBERTReranker:
    def __init__(self, model_name="colbert-ir/colbertv2.0"):
        self.model_name = model_name
        self.model = None    # Lazy Loading

    def _load_model(self):
        """ColBERT v2 모델 로드 (HuggingFace에서 다운로드)"""
        from transformers import AutoTokenizer, AutoModel
        self.tokenizer = AutoTokenizer.from_pretrained(self.model_name)
        self.model = AutoModel.from_pretrained(self.model_name)

    def rerank(self, query, candidates, clip_captions, top_k=20):
        """ColBERT Late Interaction으로 상위 후보 재순위"""
        self._load_model()

        # 1. 쿼리 인코딩: "dog in park" → 각 토큰의 벡터
        query_vecs = self._encode_text(query)    # [n_query_tokens, 128]

        scored = []
        for clip_id, wrrf_score in candidates:
            caption = clip_captions.get(clip_id, "")
            # 2. 문서(캡션) 인코딩
            doc_vecs = self._encode_text(caption)  # [n_doc_tokens, 128]
            # 3. Late Interaction: 쿼리 각 토큰과 문서 각 토큰 간 최대 유사도 합산
            #    "dog"과 "canine" 의미적 유사 → 높은 점수
            #    "park"과 "forest" 의미적 유사 → 높은 점수
            sim_matrix = query_vecs @ doc_vecs.T   # [n_q, n_d] 유사도 행렬
            max_sims = sim_matrix.max(dim=1).values # 쿼리 토큰별 최대 유사도
            colbert_score = max_sims.sum().item()    # 합산 → 최종 ColBERT 점수
            scored.append((clip_id, colbert_score))

        scored.sort(key=lambda x: x[1], reverse=True)
        return [ClipResult(clip_id=cid, score=s, ...) for cid, s in scored[:top_k]]
```

ColBERT의 Late Interaction은 토큰 수준 매칭을 가능하게 한다. 예를 들어 쿼리 "dog in park"과 문서 "beautiful canine in forest"에서, "dog"-"canine"의 의미적 유사도와 "park"-"forest"의 유사도를 세밀하게 계산할 수 있다.

```python
class VisualScorer:
    def score(self, frame):
        """프레임의 시각적 품질 점수 계산"""
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        # LAPLACIAN 필터: 초점 선명도 (값이 클수록 선명)
        sharpness = cv2.Laplacian(gray, cv2.CV_64F).var()

        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        # 채도(S 채널) 평균: 색상이 얼마나 진한지
        saturation = hsv[:, :, 1].mean()

        return {'sharpness': sharpness, 'saturation': saturation}
```

```python
class TCScorer:
    def compute_tc_score(self, clips, visual_scorer, get_keyframe_fn):
        """클립 간 시각적 연속성 측정 (DINOv2 기반)"""
        similarities = []
        for i in range(len(clips) - 1):
            # 현재 클립의 마지막 프레임
            last_frame = get_keyframe_fn(clips[i], position='end')
            # 다음 클립의 첫 프레임
            first_frame = get_keyframe_fn(clips[i+1], position='start')
            # DINOv2로 두 프레임 간 코사인 유사도 계산
            sim = self._compute_dino_similarity(last_frame, first_frame)
            similarities.append(sim)

        tc_score = np.mean(similarities) if similarities else 0.0
        return {'tc_score': tc_score, 'pair_similarities': similarities}

    def interpret_score(self, score):
        if score >= 0.7: return "우수"
        elif score >= 0.5: return "양호"
        elif score >= 0.3: return "보통"
        else: return "주의"
```

```python
class TransitionSelector:
    def select_transitions(self, clips):
        """연속 클립 쌍의 DINOv2 유사도로 트랜지션 자동 결정"""
        transitions = []
        for i in range(len(clips) - 1):
```

```python
class VideoAssembler:
    def __init__(self, output_dir="output"):
        self.output_dir = output_dir
        self.colour_normalizer = ColourNormalizer()
        self.visual_scorer = VisualScorer()
        self.transition_selector = TransitionSelector()

    def assemble(self, clips, query, max_clips=10, sort_mode="manual"):
        """Top-K 클립을 실제 영상으로 조립"""
        sub_latencies = {}

        # 1. 클립 정렬
        t0 = time.perf_counter()
        if sort_mode == "auto":
            clips = self._perception_sort(clips)  # 시각 유사도 자동 정렬
        elif sort_mode == "hybrid":
            clips = self._hybrid_sort(clips)      # 첫/끝 고정, 중간 자동
        sub_latencies['sort'] = (time.perf_counter() - t0) * 1000

        # 2. 클립 추출 (ffmpeg로 원본 영상에서 구간 잘라내기)
        extracted_paths = []
        for clip in clips[:max_clips]:
            out_path = self._extract_clip(clip)   # ffmpeg -ss start -t duration
            extracted_paths.append(out_path)

        # 3. 색보정 적용
        self.colour_normalizer.normalize(extracted_paths)

        # 4. 트랜지션 결정
        transitions = self.transition_selector.select_transitions(clips)

        # 5. 최종 영상 합성 (ffmpeg concat)
        output_path = self._concat_with_transitions(extracted_paths, transitions)
        # H264 코덱, 30fps, 1280x720 해상도로 인코딩
        return output_path, transitions, sub_latencies
```

```python
class C2PATagger:
    def build_manifest(self, query, clips):
        """C2PA 매니페스트 객체 생성"""
        source_clips = [
            {"clip_id": c.clip_id, "video_path": c.video_path,
             "start_ms": c.start_ms, "end_ms": c.end_ms, "score": c.score}
            for c in clips
        ]
        return C2PAManifest(
            query=query,
            timestamp=datetime.utcnow().isoformat() + "Z",
            source_clips=source_clips
        )

    def sign_manifest(self, manifest):
        """ES256 (ECDSA P-256 + SHA-256) 전자서명"""
        from cryptography.hazmat.primitives.asymmetric import ec
        private_key = ec.generate_private_key(ec.SECP256R1())  # P-256 키 생성
        data = json.dumps(manifest.to_dict(), sort_keys=True).encode()
        signature = private_key.sign(data, ec.ECDSA(hashes.SHA256()))
        manifest.signature = signature.hex()  # 서명을 hex 문자열로 저장

    def embed_c2pa(self, video_path, manifest):
        """영상 파일의 메타데이터에 C2PA JSON 임베드"""
        c2pa_path = video_path.replace('.mp4', '_c2pa.json')
        with open(c2pa_path, 'w') as f:
            json.dump(manifest.to_dict(), f, indent=2)
        return c2pa_path
```

```python
def _run_search_pipeline(self, query, top_k=20):
    self.load_index()              # 138행: 인덱스 미로드 시 로드
    tracker = LatencyTracker()

    # Phase 0: 쿼리 전처리 (한→영 번역)
    tracker.start("phase0_preprocess")
    pq = self.query_preprocessor.preprocess(query)  # 159행: 언어감지 + 번역
    en_query = pq.en_query                           # 160행: 영어 쿼리
    tracker.stop("phase0_preprocess")

    # Phase 1: BM25 Sparse Search (~5ms)
    tracker.start("phase1_bm25")
    sparse_results = self.bm25.search(en_query, top_n=100)  # 177행: 상위 100개
    tracker.stop("phase1_bm25")

    # Phase 1: Dense Retrieval — 임베딩 + FAISS 분리 측정
    tracker.start("phase1_embed")
    query_vec = self.embedder.encode_query(en_query)  # 188행: 텍스트→512차원 (~200ms)
    tracker.stop("phase1_embed")

    tracker.start("phase1_faiss")
    dense_results = self.dense_retriever.search(query_vec, top_k=100)  # 192행: FAISS (~5ms)
    tracker.stop("phase1_faiss")

    # Phase 2: WRRF Fusion (~5ms)
    tracker.start("phase2_fusion")
    fused_results = self.hybrid_fusion.fuse(sparse_results, dense_results)  # 206행: 순위 합산
    tracker.stop("phase2_fusion")

    # Phase 3: ColBERT Reranking (~350ms)
    tracker.start("phase3_reranking")
    clip_captions = {cid: self.clip_metadata[cid].caption
                     for cid, _ in fused_results[:100]}     # 218행: 상위 100개 캡션 추출
    reranked = self.reranker.rerank(en_query, fused_results[:100],
                                     clip_captions, top_k=top_k)  # 223행: ColBERT 재순위

    # 메타데이터 보강: 각 클립에 video_path, start_ms 등 채우기
    for clip in reranked:
        if clip.clip_id in self.clip_metadata:
            meta = self.clip_metadata[clip.clip_id]
            clip.video_path = meta.video_path     # 231행: 원본 영상 경로
            clip.start_ms = meta.start_ms         # 232행: 시작 시간
            clip.end_ms = meta.end_ms             # 233행: 종료 시간
    tracker.stop("phase3_reranking")

    return en_query, reranked, tracker
```

```python
def extract_frames_b64(video_path):
    """영상에서 8프레임 균등 추출 → base64 리스트"""
    cap = cv2.VideoCapture(video_path)
    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    indices = np.linspace(0, total - 1, N_FRAMES, dtype=int)  # 8개 균등 간격 인덱스
    for idx in indices:
        cap.set(cv2.CAP_PROP_POS_FRAMES, idx)
        ret, frame = cap.read()
        frame = cv2.resize(frame, (512, 288))                 # 512x288로 리사이즈
        _, buf = cv2.imencode('.jpg', frame, [cv2.IMWRITE_JPEG_QUALITY, 85])  # JPEG 85%
        frames.append(base64.b64encode(buf).decode('utf-8'))   # base64 인코딩
    return frames

def generate_caption(video_path, max_retries=5):
    """GPT-4o-mini Vision으로 영문 캡션 생성"""
    frames = extract_frames_b64(video_path)
    image_contents = [{"type": "image_url",
                       "image_url": {"url": f"data:image/jpeg;base64,{b64}", "detail": "low"}}
                      for b64 in frames]
    messages = [
        {"role": "system", "content": "You are an expert video analyst."},
        {"role": "user", "content": [
            {"type": "text", "text": "Write one detailed English sentence describing what happens."},
            *image_contents                        # 8장의 프레임 이미지
        ]}
    ]
    resp = client.chat.completions.create(
        model="gpt-4o-mini", messages=messages,
        max_tokens=150, temperature=0.3)           # temperature 0.3으로 안정적 출력
    return resp.choices[0].message.content.strip()

# 메인 루프: 50개마다 체크포인트 저장
for i, vid in enumerate(tqdm(remaining)):
    caption = generate_caption(video_path)
    new_captions[vid] = caption
    if (i + 1) % 50 == 0:
        save_checkpoint(new_captions, CHECKPOINT_PATH)  # Drive에 중간 저장
    time.sleep(0.5)                                      # Rate limit 방지
```

`detail="low"`로 API 비용을 최소화한다. 8프레임을 보내면 GPT-4o-mini가 영상의 전체 맥락을 파악하여 한 문장 캡션을 생성한다.

```python
def compute_retrieval_metrics(ranked_ids, gt_video_id):
    """단일 쿼리의 R@1, R@5, R@10, rank 계산"""
    rank = ranked_ids.index(gt_video_id) + 1  # 1-indexed (정답이 몇 위?)
    return {
        'r1':  1.0 if rank <= 1  else 0.0,    # 1위 안에 있으면 1, 아니면 0
        'r5':  1.0 if rank <= 5  else 0.0,    # 5위 안에 있으면 1
        'r10': 1.0 if rank <= 10 else 0.0,    # 10위 안에 있으면 1
        'rank': rank,
    }

def run_dense_eval(eval_pairs, embedder, eval_store):
    """1000개 쿼리 전체 평가"""
    for caption, gt_vid in eval_pairs:
        query_vec = embedder.encode_query(caption)      # 캡션 → 512차원 벡터
        ranking = eval_store.full_ranking(query_vec)     # 전체 1000개 순위
        metrics = compute_retrieval_metrics([vid for vid, _ in ranking], gt_vid)
    # R@1 = 1000개 쿼리의 r1 평균 × 100 (%)
```

## 11. 시스템 설계 원칙과 트레이드오프

### 11-1. Scene vs Shot: 기본 단위의 선택

초기에는 shot(~3초)을 기본 단위로 사용했으나, PD가 "5개 장면을 찾아줘"라고 하면 3초짜리 15개 조각이 나왔다. v3에서 Agglomerative Clustering으로 scene(~30초)을 기본 단위로 삼아 의미적으로 자연스러운 블록을 제공한다.

### 11-2. BM25 + Dense의 하이브리드 검색

BM25는 정확하지만 어휘 불일치 문제가 있다("개" vs "강아지"). Dense는 의미를 보지만 환각 가능성이 있다. WRRF로 합치면 두 경로 모두에 나타난 클립이 우선 정렬되어 상호 보완된다.

### 11-3. 영어 기반 검색 인덱스

InternVideo2, CLIP 등 영상 임베딩 모델이 영어 기반으로 훈련되어 있기 때문에, 모든 검색을 영어로 수행한다. 한국어 입력은 Papago로 번역하여 시스템 일관성과 성능을 유지한다.

### 11-4. T4 GPU VRAM 제약

Colab T4의 16GB VRAM에서 InternVideo2-1B(float16, ~4-6GB) + ColBERT를 동시에 운용한다. batch_size=16, flash_attention 대신 일반 attention을 사용하는 것은 모두 VRAM 효율을 위한 선택이다.

## 12. 파이프라인 실행 흐름 (End-to-End)

PD가 한국어 쿼리 "밤에 도시 야경을 보여주는 영상"을 입력하면:

1. **QueryPreprocessor**: 한국어 감지 → Papago API → "night city landscape"
2. **BM25**: 캡션에서 "night", "city" 포함 상위 100개 (~5ms)
3. **Dense**: 쿼리→512차원 벡터(~200ms) → FAISS 코사인 유사도 상위 100개(~5ms)
4. **HybridFusion**: WRRF 가중 합산 → 상위 20개 (~1ms)
5. **ColBERT**: 토큰 수준 정밀 재순위 → 상위 5개 (~500ms)
6. **VideoAssembler**: 클립 추출(~10s) + 색보정(~1s) + 트랜지션(~2s) + ffmpeg 인코딩(~30s)
7. **TCScorer**: DINOv2로 클립 간 시각적 유사도 → TC-Score (~5s)
8. **C2PATagger**: JSON 메타데이터 생성 + ES256 서명 (~100ms)
9. **VideoRAGResult**: 영상 경로, 클립 목록, TC-Score, C2PA 매니페스트 반환

전체 E2E: ~1초(검색) + ~0.5초(리랭킹) + ~50초(어셈블리) ≈ 51초.

---

이 문서가 VideoRAG 프로토타입의 전체 구조와 흐름을 이해하는 데 도움이 되기를 바란다. 각 모듈은 독립적이면서도 서로 잘 협력하도록 설계되어 있으며, 필요에 따라 개별 모듈을 개선하거나 교체할 수 있는 구조를 가지고 있다.
